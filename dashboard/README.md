# 🐾 YhasClaw Dashboard

Dashboard de monitoreo en tiempo real para YhasClaw.

## 📊 ¿Qué muestra?

### 1. Señales de Trading
- Datos en tiempo real de Smart Money de Binance
- Tokens con señales de compra/venta
- Indicadores de ganancia máxima

### 2. Skills Activos
- 122 skills instalados
- Categorizados por función:
  - 💰 Finanzas/Trading (10)
  - 📱 Marketing (4)
  - 💻 Desarrollo (15)
  - 📧 Productividad (50+)

### 3. Planes Actuales
- Objetivo: Generar ingresos autónomos
- Estado actual y próximos pasos
- Bloqueos identificados

### 4. Actividad Reciente
- Log de todas las acciones
- Timestamps exactos
- Detalles de cada evento

### 5. Métricas
- Skills totales
- Señales activas
- APIs configuradas

## 🔧 Para Activar Funciones Autónomas

### Trading Automático
Necesito del Jefe:
```
BINANCE_API_KEY=xxxx
BINANCE_API_SECRET=xxxx
```

### Marketing Automático
Necesito del Jefe:
```
TWITTER_API_KEY=xxxx
TWITTER_API_SECRET=xxxx
TWITTER_ACCESS_TOKEN=xxxx
TWITTER_ACCESS_SECRET=xxxx
```

### Pagos Automáticos
Necesito del Jefe:
```
STRIPE_API_KEY=xxxx
# o
PAYPAL_CLIENT_ID=xxxx
PAYPAL_CLIENT_SECRET=xxxx
```
