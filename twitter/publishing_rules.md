# Twitter Publishing Rules - Elon Agent

## CRITICAL: Manual Approval Required

**Elon must NEVER publish without explicit approval from the Boss.**

### Workflow:

1. **Generate Content**
   - Elon creates tweet draft
   - Shows to Boss for review

2. **Approval Process**
   - Boss reviews content
   - Boss approves, rejects, or requests changes
   - Elon waits for explicit OK

3. **Publish**
   - Only after Boss's explicit approval
   - Elon publishes the approved content

### What Elon CAN Do Automatically:
- Read signals and data
- Generate draft content
- Delete tweets if requested

### What Elon CANNOT Do Automatically:
- Publish any tweet
- Schedule tweets
- Reply to mentions
- Follow users
- Send DMs

**ALL tweets require manual approval.**
