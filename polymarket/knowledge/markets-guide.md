# Polymarket Markets Guide

## 🌐 Platform Overview

Polymarket is a decentralized prediction market platform built on Polygon. It uses a Central Limit Order Book (CLOB) for peer-to-peer trading with non-custodial settlement via smart contracts.

### Key Features:
- **Binary Markets**: Yes/No outcomes, winning tokens redeem for $1
- **Multi-Outcome Events**: Negative risk markets where No on one outcome = Yes on all others
- **UMA Resolution**: Decentralized, permissionless resolution via Optimistic Oracle
- **No Trading Size Limits**: Any amount can be matched
- **Low Fees**: Geopolitical markets are FREE; other categories 0.75-1.80% peak

## 🔧 Market Selection Criteria

### Ideal Market Characteristics:

| Factor | Target | Why |
|--------|--------|-----|
| Spread | < 0.02 (2 cents) | Lower cost to enter/exit |
| Liquidity | > $50,000 | Sufficient depth, less slippage |
| Volume 24h | > $10,000 | Active trading, easier fills |
| Confidence | High edge vs market | Value betting edge |
| Resolution | Clear criteria | Less dispute risk |

### Warning Signs (Avoid):
- Spread > 5 cents (illiquid)
- Volume < $1,000 (stale market)
- Ambiguous resolution rules
- Long resolution times with no updates
- `closed: true` or `acceptingOrders: false`

## 📊 Reading Market Data

### Key API Fields:
```typescript
{
  "id": "market_id",
  "question": "Will X happen?",
  "outcomePrices": "[\"0.45\", \"0.55\"]", // [Yes, No]
  "bestBid": 0.44,  // Highest buy order
  "bestAsk": 0.46,  // Lowest sell order
  "spread": 0.02,   // ask - bid
  "volume": "123456.78",
  "liquidity": "12345.67",
  "liquidityNum": 12345.67,
  "volume24hr": "1234.56",
  "clobTokenIds": ["yes_token", "no_token"],
  "negRisk": false,  // Multi-outcome event?
  "feesEnabled": false,  // Are fees charged?
  "active": true,
  "closed": false,
  "endDate": "2026-12-31T12:00:00Z",
  "orderPriceMinTickSize": 0.01,  // Price precision
  "orderMinSize": 5,  // Minimum order size
  "rewardsMinSize": 20,  // For liquidity rewards
  "rewardsMaxSpread": 3.5,  // Max spread for rewards
}
```

### Spread Calculation:
```
displayPrice = (bestBid + bestAsk) / 2
spread = bestAsk - bestBid

Example:
bid = 0.44, ask = 0.46
displayPrice = 0.45 (45% implied probability)
spread = 0.02 (2 cents)
```

## ⏰ Timing Considerations

### Market Lifecycle:
1. **Launch**: High volatility, wide spreads
2. **Active Trading**: Tighter spreads, more liquidity
3. **Near Resolution**: Spreads tighten, volume spikes
4. **Resolution**: Trading stops, tokens redeemable

### Best Entry Points:
- **Early**: After initial volatility settles
- **Mid**: During price discovery after news
- **Late**: Before resolution (if outcome clear)

### Order Timing:
- Use GTD orders before known events
- Cancel stale orders quickly
- Batch orders with `postOrders()` for lower latency

## 🌐 API Endpoints Quick Reference

### Gamma API (Public, Read-Only)
```bash
# List active markets
GET https://gamma-api.polymarket.com/markets?active=true&closed=false

# Get specific market
GET https://gamma-api.polymarket.com/markets/{id}

# List events (multi-market containers)
GET https://gamma-api.polymarket.com/events?active=true

# Search markets
GET https://gamma-api.polymarket.com/markets?slug={market_slug}
```

### CLOB API (Trading)
```bash
# Get orderbook
GET https://clob.polymarket.com/book?token_id={token_id}

# Get tick size
GET https://clob.polymarket.com/tick-size?token_id={token_id}

# Get fee rate
GET https://clob.polymarket.com/fee-rate?token_id={token_id}

# Place order (requires L2 auth)
POST https://clob.polymarket.com/order

# Cancel order
DELETE https://clob.polymarket.com/order/{order_id}
```

## 📝 Resolution Rules Best Practices

### Always Read Full Resolution Criteria:
1. **Primary Resolution Source**: Official records, specific websites
2. **End Date**: When market becomes eligible for resolution
3. **Special Conditions**: "If X doesn't happen by Y, resolves 50-50"
4. **Clarifications**: Check for any "Additional context" updates

### Common Resolution Types:
- **Binary (Yes/No)**: Most common
- **Multi-Outcome**: Use negative risk
- **Scalar**: Rare, specific outcome ranges
- **Categorical**: Multiple choice (use neg risk)

### Dispute Risk:
- UMA bond: $500-750 USDC.e typically
- Challenge period: 2 hours
- Resolution extension if disputed: +4-6 days
