### 2. Nginx timeout
- Default: 60s timeout
- Firecrawl scraper tarda ~20s
- Fix: proxy_read_timeout 60s en nginx config

### 3. Dashboard data loading
- Problema: JSON externo no cargaba (caché/nginx)
- Solución: API REST + JavaScript fetch con nocache

### 4. Python scripts en OpenClaw
- "complex interpreter invocation detected" = usar shell wrapper
- No se puede: `python3 script.py "arg1" "arg2"` directamente
- Sí se puede: `bash wrapper.sh arg1 arg2`

### 5. Edit tool limitations
- Edits no siempre se guardan si el texto oldText no es único
- Mejor: reescribir secciones completas o usar shell para editar
